# Анализ данных поездок желтого такси Нью-Йорка (NYC Taxi Data Analysis)

Учебный проект по дисциплине «Интеллектуальный анализ данных / Программирование на Python», выполняющий полный цикл ETL (извлечение, преобразование, загрузка), оптимизацию хранения и сравнение производительности СУБД (SQLite и PostgreSQL).

## Требования
- Python 3.12.14
- Poetry (управление зависимостями)
- PostgreSQL (pgAdmin 4)

## Структура проекта
- `data/` — папка с данными (сырые, промежуточные, обработанные)
- `notebooks/` — Jupyter Notebooks с пошаговым выполнением лабораторной
- `src/` — исходный код скриптов (очистка, загрузка в БД)
- `sql/` — файлы схем баз данных (`.sql`)
